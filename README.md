## Reflexão: Tailwind CSS vs CSS tradicional

O **Tailwind CSS** tem como vantagens a rapidez na estilização, a padronização visual e a praticidade de aplicar estilos diretamente nos componentes React, sem precisar criar arquivos CSS separados. Como desvantagens, pode deixar o código mais poluído com muitas classes, dificultar a leitura e exigir aprendizado de sua sintaxe específica.
